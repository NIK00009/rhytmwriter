# Studio Irama Tahun 6

Aplikasi mencipta corak irama meter 4/4. HTML, CSS dan JavaScript; tiada pemasangan atau backend diperlukan.

## Cara deploy di GitHub Pages

1. Ekstrak ZIP ini pada komputer.
2. Cipta repository GitHub (pilih Public untuk GitHub Pages percuma).
3. Muat naik index.html, README.md dan .nojekyll ke akar repository. Jangan muat naik ZIP sahaja.
4. Buka Settings > Pages.
5. Di Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder / (root), kemudian Save.
7. Tunggu deployment selesai. Pautan aplikasi akan muncul pada halaman Pages.

## Cara guna

- Pilih salah satu daripada empat bar, kemudian tekan not atau tanda rehat.
- Setiap bar yang digunakan perlu cukup 4 detik sebelum main balik.
- Tekan simbol dalam bar untuk memadamnya, atau gunakan Undur.
- Mainkan memberikan kiraan masuk 4 detik. Pilih tempo, bunyi perkusi dan Ulang.
- Tab Cabaran menyediakan empat corak permulaan secara bergilir.
- Simpan ciptaan menyimpan satu ciptaan pada pelayar/peranti yang sama; tiada penyelarasan antara peranti.
- Cetak menggunakan dialog cetakan pelayar; pilih Save as PDF jika perlu.

## Kandungan

Krocet (1), kuaver (0.5), krocet bertitik (1.5), minim (2), rehat krocet (1), rehat kuaver (0.5), rehat minim (2).
Bunyi perkusi ialah simulasi sintesis, bukan rakaman alat sebenar.
Fon Google dimuatkan jika internet tersedia; fon sistem digunakan sebagai gantian.

## Semakan

Sintaks JavaScript, nilai not, empat bar contoh dan empat corak cabaran telah disemak.
Audio dan paparan belum diuji melalui pelayar dalam sesi penyediaan.
